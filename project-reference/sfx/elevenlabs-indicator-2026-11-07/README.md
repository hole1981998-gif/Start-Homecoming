# Thêm tiếng xi nhan — 07/11/2026

Hai tiếng relay đơn mới được tạo bằng ElevenLabs Sound Effects v2; prompt và thông số ở `generate.mjs`. API key đọc từ file môi trường nằm ngoài Git. Mỗi file dài khoảng 0,65 giây và được game lặp trong lúc xi nhan bật. Game giữ cả tiếng xi nhan cũ, chọn một trong ba kiểu theo seed ở mỗi lần bật mới, tránh lặp ngay kiểu vừa dùng.

Nghe từng file ở `LISTEN.html`. Trong game, giữ A/D hoặc chọn Q/E đúng giao lộ để thử loop; nhả nút để dừng. Gain chung của xi nhan tăng cùng đợt này.
