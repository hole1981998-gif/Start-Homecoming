# Interaction and crossing sounds — 6 November 2026

ElevenLabs Sound Effects v2 generated two short padded person impacts, two vendor-cart crashes, one turn-indicator relay tick and one four-second seamless train-crossing loop. Exact prompts and settings are in `generate.mjs`; the key stays outside the repo in an ignored environment file. `LISTEN.html` plays each clip for local review.

The person thump accompanies a real roadside passenger hit and police/militia body contact; the existing scream remains a separate voice. Vendor-cart impacts replace the prior generic cart crash. The indicator ticks only during A/D steering or a valid Q/E junction choice, sharing one cooldown. Train audio starts only while a nearby train is actively crossing and fades when it is gone. Player and NPC pothole impacts are raised one mix step. No new game event or balance value is introduced.
